# Notice
> 当前仓库是一个试验性项目，开源是我们临时想出来的方案，所以粗糙地感到无地自容...

于是我们计划正在开发 v2 版本，将会开源大部分我们的工作，并且为了开源，我们创建了 Organization **HackHTU-Team**

我们将从 ui-based 开始设计（CC BY 2.0），然后设计自己的 Style/Component（GPL-2.0），最后重新编写我们的落地页，我们还准备增加 PWA APP 避免我们的域名被封的情况

对于Code 我们仍然采用 ServerLess 架构，这仍是一个偏向前端的技术栈，假定技术栈如下，我们在寻求您的帮助

### Frontend: 
1. Landing Page: Vite + Vue + TailwindCSS + (Animation)GSAP + (3D)Three.js
2. PWA APP: (Push) Firebase
   
### Backend:
1. Hono(A Framework for Edge Network)

### Persistence：
1. Cloudflare KV/R2/D1

同时，我们在寻求 Free Domain 等有关建议。

> 您可以发 issue 或者从下面的「加入我们」联系我们
